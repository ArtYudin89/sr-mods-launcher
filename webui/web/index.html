Профили модов

Нажмите на профиль, чтобы переключиться (текущий отмечен). Окно остаётся открытым.
Добавить в текущий профиль все моды из одной сборки. Затем нажмите «Установить моды».
Профиль — это переносимый набор: база + список модов. Можно отдать другому игроку.

Добавить в профиль

Добавьте движок и моды этой сборки в профиль. Затем нажмите «Установить моды».
Загрузка списка сборок…
Любая сборка сразу. У каждого мода — метка сборки.
Какую ветку модов берём. Движок можно поставить только от одной сборки, моды — из любых.
«Вся сборка» — движок и все её моды. Отдельно: «Базовые файлы игры» — только движок (Rangers.exe, DATA, CFG + фиксы к базе), «Все моды сборки» — только моды. Иначе выберите конкретный пак.
«Весь пак» — добавить пак целиком. Иначе — один мод из пака.
Прямая ссылка на файл <id>.json форка мода (GitHub/HF).

Папка игры

Нажмите на путь к игре в шапке и выберите папку с Rangers.exe.

Профили модов

Откройте управление профилями кнопкой с плюсом рядом со списком «Профиль».

Добавить в профиль

Нажмите «Добавить мод» над списком. В открывшемся окне найдите мод или выберите целую сборку.

Установка и обновление

«Установить моды» скачивает моды из профиля. Для обновления сначала нажмите «Проверить обновления», затем «Обновить моды».

Базовая сборка

Задайте сборку для проверки обновлений. «Авто» определяет её по файлам в папке Mods.

Запуск игры

Нажмите «Играть» в правом верхнем углу. Вкладка «Игра» позволяет перенести список подключённых модов между профилем и игрой.
